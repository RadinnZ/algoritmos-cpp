# Exercícios de Funções

Exercícios de funções e procedimentos em C++ (passagem por valor, passagem por referência, retorno de valores) — parte da disciplina de Algoritmos e Programação, UNIVALI.

| # | Arquivo | Descrição |
|---|---------|-----------|
| Q01 | [func_q01_sinal.cpp](func_q01_sinal.cpp) | Função que verifica se um número é positivo ou negativo |
| Q02 | [func_q02_dobrar_valor.cpp](func_q02_dobrar_valor.cpp) | Procedimento que dobra um valor por parâmetro (passagem por valor) |
| Q03 | [func_q03_trocar.cpp](func_q03_trocar.cpp) | Procedimento que troca dois valores (passagem por referência) |
| Q04 | [func_q04_peso_ideal.cpp](func_q04_peso_ideal.cpp) | Função que calcula o peso ideal a partir de altura e sexo |
| Q05 | [func_q05_castigo.cpp](func_q05_castigo.cpp) | Procedimento que imprime uma frase N vezes |
| Q06 | [func_q06_resto_sem_modulo.cpp](func_q06_resto_sem_modulo.cpp) | Função que calcula o resto da divisão sem usar o operador `%` |
| Q07 | [func_q07_quociente_resto.cpp](func_q07_quociente_resto.cpp) | Procedimento que calcula quociente e resto (parâmetros por referência) |
| Q08 | [func_q08_mdc.cpp](func_q08_mdc.cpp) | Função que calcula o M.D.C. entre dois números (algoritmo de Euclides por subtração) |
| Q09 | [func_q09_serie.cpp](func_q09_serie.cpp) | Função que calcula o valor de uma série S com termo geral (1 + i²) / i |

## Como compilar

```bash
g++ -o exec arquivo.cpp
./exec
```
