## 📝 Sequenciais

Exercícios focados em entrada de dados, operações aritméticas e saída de resultados, sem uso de estruturas de controle de fluxo.

| # | Arquivo | Descrição |
|---|---|---|
| Q01 | [seq_q01_nome.cpp](./sequenciais/seq_q01_nome.cpp) | Lê o nome do usuário e exibe uma saudação |
| Q03 | [seq_q03_ferraduras.cpp](./sequenciais/seq_q03_ferraduras.cpp) | Calcula a quantidade de ferraduras para um haras |
| Q05 | [seq_q05_salario_joao.cpp](./sequenciais/seq_q05_salario_joao.cpp) | Calcula o saldo restante do salário após pagar contas com multa |
| Q06 | [seq_q06_lanchonete.cpp](./sequenciais/seq_q06_lanchonete.cpp) | Calcula ingredientes necessários para produção de sanduíches |
| Q07 | [seq_q07_combustivel.cpp](./sequenciais/seq_q07_combustivel.cpp) | Calcula o custo de combustível de uma viagem |
| Q08 | [seq_q08_media_ponderada.cpp](./sequenciais/seq_q08_media_ponderada.cpp) | Calcula a média ponderada de três provas com pesos 2, 4 e 6 |
